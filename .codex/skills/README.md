# Repo Local Skills

These skills are lightweight, repo-specific guidance for Codex-style agents working on this Godot project.

## Available Skills

- `lightweight-superpowers`
  - Use for normal day-to-day work in this repo.
  - Keeps the superpowers workflow intentionally light.
- `godot-change-checklist`
  - Use before closing gameplay, scene, or UI changes.
  - Focuses on Godot scene bindings, signals, and manual smoke-test coverage.

If your platform does not auto-discover repo-local skills, open the corresponding `SKILL.md` directly and apply it as a checklist.
